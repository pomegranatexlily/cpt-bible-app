# Oustory — Feature, Layout & Culture Plan, execution record

Source: user-provided *The Bible App — Feature, Layout & Culture Plan* (7 pages, prepared October 16, 2026) and earlier *Doctrinal-Drift Editorial Notes* (38-page draft). This page records actual implemented components, not a claim that every proposal is approved.

## Completed in the first feature run
- Preserve the full **80-book**, **1,362-chapter**, **36,801-source-verse** editable reading edition. The 23 earlier master-based books are retained unchanged; the other 57 books remain provisional. The six numbered source-witness holds remain explicit.
- Add covenant-centered **Home** screen, always quoting from the real Oustory verse data, with a continue-reading link. An eight-theme weekly cycle covers The Name, The Covenant, The Nation, The King, The Law, The Land, The Assembly, and The Return. This is a deterministic theme rotation, **not** a claim of an approved lunar Sabbath or feast calendar.
- Add a **tap-any-verse** sheet with plain-text sharing/copying, local highlights and a "Why this rendering" note or an explicit note-not-yet-indexed message. No Scripture text is overwritten by displaying commentary.
- Index **17** editorial notes linking **25** verse references. Distinguish founder rulings, provisional interpretations, draft notes, and genuine textual holds. These initial notes are grounded in the earlier founder decisions and the doctrinal-drift draft, not presented as a fully sealed 63-note apparatus.
- Add **Study** topics based on the plan's fifteen covenant categories, each with a true Bible passage anchor. Add a local highlights view and access to saved chapter bookmarks.
- Add **Discover** with four usable, chapter-linked reading tracks: Torah Foundations, The Nation's Story, The Prophets: Covenant Enforcement, and The Anointed King; reading-step completion is stored locally.
- Add responsive **Home / Bible / Study / Discover / More** mobile navigation. "Nation" community services are intentionally *not* shown as a fake functioning tab before a backend/directory is available.
- Use serif typography for Scripture and modest archival/gold accents; no fictional religious photography or generated biblical imagery.
- Add chapter-specific provenance disclosure on provisional books.
- Add GitHub Actions mobile browser smoke tests with screenshot artifacts: Home, Bible, Study, Discover, tap-verse dialogs, and all 80 book-picker entries.
